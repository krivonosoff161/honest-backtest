## Completed

- Stable seven-layer deterministic validation toolkit and named overfitting
  statistics.
- Nine synthetic worked examples and 77 test functions on the review tree,
  including the documentation contract tests.
- Public-safe validation bridge with paper-only positive ceiling.
- Experimental Strategy Lab inventory, registry, queue, advisory budget, and
  guarded proposal surfaces.

## Current

- Align canonical documentation and the local Trading Portfolio projection
  with the verified repository state.
- Keep stable validation and experimental discovery clearly separated.
- Prevent historical phase plans from appearing to be current authority.

## Next

- Strengthen time-series-aware inference and explicitly test dependence
  assumptions.
- Version cross-repository validation artifacts and verify complete trial-set
  provenance.
- Add synthetic compatibility fixtures for producer/validator schema changes.
- Preserve the rule that a positive verdict means paper/forward observation
  only.

## Later

- Expand adversarial and regime robustness methods only when they catch a
  distinct, evidenced failure class.
- Evaluate advisory model usefulness against immutable held-out evidence; model
  output remains a proposal.
- Improve forward-evidence integrity without turning this repository into a
  runtime or execution system.

## Permanently Outside This Roadmap

Private strategies, live market/account data, broker connectors, order
placement, profitability claims, and execution authority remain outside this
repository. Any future change to that boundary requires a separate architecture
and owner decision.
